Reads text-based question papers from Narayana, Allen, FIITJEE and similar formats: sections, question counts, question types, marks, paragraphs and the answer key are taken from the PDFs themselves. You check everything below before saving. Scanned PDFs (photos) do not work.

1. Marking scheme

One row per section found in the paper. Change a row and every question in that section follows.

2. Check every question

Crop wrong? ▲▼ move the top or bottom edge of the crop (8pt a step). Answer: letters for single / matching / multi (BCD), numbers as printed, ranges as 0.78 TO 0.82. Typed text is optional (HTML with \( \) math); when filled it replaces the crop.

3. Publish to the exam site (GitHub)

Commits the paper into the repository that hosts the exam site. Use a fine-grained personal access token limited to that repository with Contents: read and write. The token stays in this browser only if you tick remember.
